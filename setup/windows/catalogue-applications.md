| Catégorie | Application | Installation | Remarque |
|---|---|---|---|
| Jeux | Riot Client | [site officiel](https://www.riotgames.com/en/download) | WinGet ne propose pas de paquet Riot Client générique ; ses entrées disponibles ciblent des jeux et des régions spécifiques. |
| Broderie | Hatch Embroidery (Wilcom) | [site officiel](https://wilcom.com/) | Installation depuis le compte Wilcom ; licence ou compte requis. |
| Audio | Ableton Live | [site officiel](https://www.ableton.com/live/) | Installer depuis Ableton l'édition correspondant à la licence souhaitée. |
| Cybersécurité défensive | Windows Sandbox | [site officiel](https://learn.microsoft.com/windows/security/application-security/application-isolation/windows-sandbox/) | Fonctionnalité Windows à activer manuellement ; nécessite une édition compatible, la virtualisation et peut demander un redémarrage. |
| IA locale | AnythingLLM Desktop | [site officiel](https://docs.anythingllm.com/installation-desktop/windows) | Interface pour créer des agents et espaces de travail avec un moteur local intégré. Installer pour l'utilisateur courant et choisir l'installeur ARM64 pour la Surface Snapdragon ou x64 pour le PC Radeon. |
| IA locale | AMD Software: Adrenalin Edition | [site officiel](https://www.amd.com/en/support/download/drivers.html) | Optionnel : pilotes et logiciel AMD pour le PC avec Radeon RX 7900 XTX uniquement ; choisir le modèle exact sur le site AMD. Ne pas installer sur la Surface Snapdragon. |
